# ASDB Brightness Keys

GNOME Shell extension that maps the built-in brightness keys to `asdbctl up` and `asdbctl down`, then shows GNOME's native brightness OSD using the brightness reported by `asdbctl get`.

## Based on Studi Brightness Control
Based on:
https://github.com/matey-0/Studi-Brightness-Control/
